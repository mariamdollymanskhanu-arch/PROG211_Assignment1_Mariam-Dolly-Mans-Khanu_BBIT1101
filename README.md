# Student Learning Portal
---

## Project Description

The **Student Learning Portal** is a Python Object-Oriented application that allows educational institutions to manage students and courses in a simple and privacy-respecting way.  

It uses only anonymized data (no real names or personal information) and follows Digital Public Goods (DPG) principles.

---

## Features

- Create and manage Students
- Create and manage Courses
- Enroll students in courses
- Store records using a dictionary
- Update status and display information
- Fully anonymized and privacy-respecting

---

## DPG Principles Alignment

| Principle                        | How it is implemented |
|----------------------------------|-----------------------|
| Open-source                      | Code published on GitHub |
| Inclusive and accessible design  | Simple command-line interface |
| Privacy-respecting               | Only anonymized IDs used (no real names) |
| Modular and reusable             | Clean `Student` and `Course` classes |

---

## Technical Requirements Met

- **Task 1**: Two classes (`Student`, `Course`) with attributes, methods, object creation and interaction
- **Task 2**: Dictionary used to store multiple objects + add/display functions
- **Task 3**: Instance methods + Class methods + Static methods
